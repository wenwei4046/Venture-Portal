# Claude Code: how to implement this handoff

1. Read `README.md`, then every file in `notes/` in numeric order.
2. Open `CRM Desktop.dc.html` and treat each frame as the spec. Lift exact values from the inline styles; don't invent spacing or colours.
3. Work one frame at a time, in this order: global rules (selected colour, names, tables) → 03 → 02 → 05/01b/12 → 06/06b/06b·2/06b·3/06c → 07 → 08 → 09b → 10 → 12b → 12c/12c·2.
4. After each frame, screenshot production at the same size and compare it with the frame. Fix every difference and every overlap before moving on.
5. Don't change behaviour that the notes don't mention. Keep production's existing data flow and routing.
6. When a value is ambiguous, ask instead of guessing.
