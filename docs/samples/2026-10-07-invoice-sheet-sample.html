手机版：
· 四张卡变 2 × 2；period 变标题下的小胶囊。
· Payroll basis 一样收起在卡下面（样板里打开给你看）：Subsidiary + Total，▾ 展开看 Basic / KPI / Allowance / EPF / SOCSO / EIS。
· Invoices 每行先看 Bill to + Amount；单号、状态 chip、日期缩成小字；▾ 展开看 Description / Category / Mode / Due；Settle → 是橘色按钮（跟 Principal 的 Approve 一样），Open the invoice → / 更多 ⋯ 是字。
· 勾了几张，底部出 Settle 条（同一个 payer 才能一起）。
· Statements 同样：Company + Net，▾ 展开看 Invoice / Contra。
· 跟 Approvals 一样，tick 和 ▾ 整格可按。
· 底部 tab bar 改英文（Overview / Approvals / Payments / Receipts / More）——Finance 和 Principal 的手机都会是这样。
